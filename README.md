# 🌐 Generalizable IoT Representation

This repository accompanies the paper

> **Generalizable IoT Traffic Representations for Cross-Network Device Identification**

submitted to the **IEEE Transactions on Network Science and Engineering (TNSE)**.

The repository serves as the public landing page for the datasets, pretrained encoder models, and software artifacts accompanying the paper.

---

## 📦 Data and Software

The complete research artifacts are hosted on Dryad:

**https://doi.org/10.5061/dryad.7h44j1098**

The Dryad release contains:

- DATA2025v1 (≈7.7 million Custom Flows)
- DATA2025v2 (≈8.8 million Custom Flows)
- Five pretrained encoder models
- Complete preprocessing pipeline
- Configuration files
- Documentation required to reproduce the experiments
